# WeatherApp

A clean and modern iOS weather application built with Swift and UIKit.

## Features
- City list with weather cards colored by condition
- Detail view with current temperature, humidity, wind, pressure
- 5-day forecast with dynamic icons
- UV index, visibility, sunrise & sunset info
- Dynamic gradients and background illustrations based on weather condition

## Tech Stack
- Swift / UIKit / Storyboard



## Requirements
- iOS 16+
- Xcode 15+
